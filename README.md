 # 🔐 Form Validation

A responsive and interactive **Form Validation project** developed using **HTML5, CSS3, and JavaScript**.

This project demonstrates how frontend form validation can be implemented using JavaScript to check user input, display validation messages, and provide a better user experience.

---

## 📌 Project Overview

The Form Validation project is designed to validate user information before submitting a form.

It checks whether the entered data meets the required conditions and provides clear validation feedback when the input is invalid.

The project focuses on creating a clean form interface and implementing client-side validation using JavaScript.

---

## 🛠️ Technologies Used

### HTML5

HTML5 is used to create the structure of the form and its input fields.

It is used for:

- Creating the form structure
- Creating input fields
- Adding labels and placeholders
- Creating password and confirm password fields
- Creating the submit button
- Organizing form sections
- Providing a proper HTML structure for validation

---

### CSS3

CSS3 is used to design and style the form interface.

It is used for:

- Creating the form layout
- Styling input fields
- Designing buttons
- Managing spacing and alignment
- Adding colors and typography
- Creating borders and rounded corners
- Styling validation error messages
- Styling valid and invalid input states
- Creating a clean and responsive user interface

---

### JavaScript

JavaScript is used to implement the main form validation functionality.

It is used for:

- Validating user input
- Checking required fields
- Validating email format
- Validating password requirements
- Confirming password matching
- Checking input length
- Displaying error messages
- Displaying validation feedback
- Handling form submission
- Preventing form submission when validation fails
- Adding and removing validation states dynamically
- Handling password visibility using the eye icon

JavaScript makes the form interactive and provides immediate feedback to the user.

## 🔍 Validation Rules

The form validates different types of user input, including:

- Required field validation
- Name/input validation
- Email format validation
- Password validation
- Confirm password matching
- Empty field detection
- Invalid input detection

When the entered information does not meet the required conditions, the application displays an appropriate validation message.
